นาย ธนดล แกมทอง

สวัสดีครับ ผมชื่อ ธนดล แกมทอง สนใจไมโครคอนโทรลเลอร์ (Microcontroller) ชอบการต่อวงจรและเขียนโปรแกรม C พื้นฐาน

ความสามารถและผลงาน

  • เขียนโปรแกรมภาษา C และ JavaScript เบื้องต้น
  • ออกแบบวงจรด้วย Arduino และเซนเซอร์พื้นฐาน
  • สร้างเว็บไซต์ Portfolio แบบ Responsive

นาย B - วิศวกรรมไฟฟ้า ปี 1

สวัสดีครับ ผมชื่อ B ชอบเรื่องระบบควบคุม (Control Systems) และการออกแบบวงจรดิจิทัล (Digital Circuits) ตอนนี้กำลังศึกษาเรื่อง Logic Gates

ความสามารถและผลงาน

  • ศึกษาระบบควบคุมและ Logic Gates
  • ทดลองสร้างวงจรดิจิทัลบน Breadboard
  • ทำโปรเจกต์จำลองระบบไฟจราจร
